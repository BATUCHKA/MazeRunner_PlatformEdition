Blackout Maze

Escape three rings of a maze in one run. Every few seconds the lights die. In the dark, purple walls shift and monsters move toward any noise you make. Each step below says exactly what to click, gives the complete code, explains how it works, and tells you how to test it.

Phase 0

Project setup

  1. A clean Godot 4.7 project to rebuild the game in, separate from the finished one.

    Do it

    1. Open Godot, click Create New Project (or + Create). Name it something like blackout-maze-mine.
    2. Renderer: Forward+ works on Mac. Pick Compatibility if you plan to export to the web.
    3. In the FileSystem dock (bottom left), right-click res:// → New → Folder and make scenes, scripts, art, levels, audio, tools and tests.
    4. Optional but smart: in a terminal, run git init in the project folder and commit after every step.

    How it works

    • Godot calls the project folder res://. Every path in code starts from there, like res://scenes/player.tscn.
    • Godot creates a hidden .godot/ folder for imported files. Never edit it; it's rebuilt automatically.

    Watch out

    • Don't build inside maze-runner--platform-edition. Keep that as your untouched answer key.

  2. A small 640×360 game screen, scaled up 2× in a 1280×720 window, with crisp pixels.

    Do it

    1. Project → Project Settings → General. Turn on Advanced Settings (toggle at the top right).
    2. Display → Window: Viewport Width 640, Viewport Height 360.
    3. Same page: Window Width Override 1280, Window Height Override 720.
    4. Same page, Stretch: Mode canvas_items, Aspect expand.
    5. Rendering → Textures: Default Texture Filter Nearest.

    How it works

    • The game is designed at 640×360. canvas_items stretch scales everything up to fill the window.
    • Nearest filtering keeps each pixel a sharp square instead of blurring it when scaled.
    • At 16 px per tile, 640×360 shows 40×22 tiles. That's why the Outer Ring (45×27) almost fits on one screen.

    Test: Press F5 later and the window should open at 1280×720.

  3. Named actions instead of hard-coded keys, so code says "run" rather than KEY_SHIFT.

    3. Click the + next to each action and press the key: A and ← for move_left, D and → for move_right, W and ↑ for move_up, S and ↓ for move_down, Shift for run, P for pause.

    • Esc already works as ui_cancel, a built-in action. The pause menu listens for both.

    • Action names must match exactly, including underscores. A typo gives no error, the key just does nothing.

  2. A timer-driven loop: Light → Warning → Dark → Light, broadcasting each change.

    Do it

    1. New script scripts/phase.gd (inherits Node). Type the code.
    2. Register as autoload Phase.
    scripts/phase.gd
    extends Node
## The blackout cycle (autoload "Phase"): LIGHT -> WARNING -> DARK -> LIGHT ...
## Everything that reacts to the lights listens to `changed`.

signal changed(phase: P)

enum P { LIGHT, WARNING, DARK }

var phase := P.LIGHT
var blackouts := 0          # how many DARK phases have finished this level
var times := { P.LIGHT: 6.0, P.WARNING: 1.0, P.DARK: 2.0 }
var timer := Timer.new()


func _ready() -> void:
    timer.one_shot = true
    add_child(timer)
    timer.timeout.connect(_next)


func start(light: float, dark: float, warning := 1.0) -> void:
    times = { P.LIGHT: light, P.WARNING: warning, P.DARK: dark }
    blackouts = 0
    _enter(P.LIGHT)


func stop() -> void:
    timer.stop()
    phase = P.LIGHT


func is_dark() -> bool:
    return phase == P.DARK


## 0..1, how much of the current phase is left.
func fraction_left() -> float:
    if timer.is_stopped():
        return 0.0
    return timer.time_left / times[phase]


func _next() -> void:
    match phase:
        P.LIGHT:
            _enter(P.WARNING)
        P.WARNING:
            _enter(P.DARK)
        P.DARK:
            blackouts += 1
            _enter(P.LIGHT)


func _enter(p: P) -> void:
    phase = p
    timer.start(times[p])
    changed.emit(p)

    How it works

    • enum P gives the three states names. Elsewhere you write Phase.P.DARK.
    • The Timer is created in code and added as a child. Its timeout signal calls _next(), which picks the next state with match.
    • blackouts counts finished dark phases. Wall shifts and the exit gate are scheduled from it.
    • fraction_left() is 1.0 at the start of a phase and 0.0 at the end, which drives the HUD bar.

    Watch out

    • Inside this file, refer to the states as P.LIGHT; from other scripts, Phase.P.LIGHT.
    • Because the Timer is a child of the autoload, pausing the game (step 40) pauses the cycle too. That's what you want.

    Test: Temporarily add print(P.keys()[p]) in _enter, and Phase.start(2, 1) in any scene's _ready. Run it and watch LIGHT, WARNING, DARK repeat in the Output panel.

    Answer key: scripts/phase.gd

## Sound effects (autoload "Sfx"). Sfx.play("pickup") for UI-style sounds,
## Sfx.play_at("growl", position) for sounds that come from a place in the world.

const SOUNDS := ["step", "rumble", "growl", "pickup", "caught", "lights_off", "lights_on",
        "tick", "gate", "heartbeat", "level_clear"]

var _streams := {}
var _players: Array[AudioStreamPlayer] = []


func _ready() -> void:
    process_mode = Node.PROCESS_MODE_ALWAYS
    for s in SOUNDS:
        _streams[s] = load("res://audio/%s.wav" % s)
    for i in 8:
        var p := AudioStreamPlayer.new()
        add_child(p)
        _players.append(p)


func play(sound: String, volume_db := 0.0, pitch := 1.0) -> void:
    for p in _players:
        if not p.playing:
            p.stream = _streams[sound]
            p.volume_db = volume_db
            p.pitch_scale = pitch
            p.play()
            return


## Plays a positional sound in the current scene; louder when the camera is close.
func play_at(sound: String, pos: Vector2, volume_db := 0.0, max_distance := 320.0) -> void:
    var scene := get_tree().current_scene
    if scene == null:
        return
    var p := AudioStreamPlayer2D.new()
    p.stream = _streams[sound]
    p.volume_db = volume_db
    p.max_distance = max_distance
    p.pitch_scale = randf_range(0.9, 1.1)
    p.global_position = pos
    p.finished.connect(p.queue_free)
    scene.add_child(p)
    p.play()

    How it works

    • play() reuses a pool of 8 players, so many sounds can overlap without creating nodes every time.
    • play_at() makes an AudioStreamPlayer2D at a world position. It gets quieter with distance from the camera and pans left/right, so you can hear where a growl came from in the dark.
    • p.finished.connect(p.queue_free) deletes the player when its sound ends.
    • PROCESS_MODE_ALWAYS keeps sounds working while the game is paused.

    Watch out

    • If a file name doesn't match the list in SOUNDS, Godot errors at startup with a failed load.

    Test: Call Sfx.play("pickup") from any _ready and you should hear a blip.

const START_LIVES := 5

var current_level := 0
var map_pieces := 0
var run_time := 0.0
var times_caught := 0
var result := ""            # "escaped" or "caught", read by the end screen
var respawn_point := Vector2.ZERO
var running := false        # true while a level is being played


func _process(delta: float) -> void:
    if running and not get_tree().paused:
        run_time += delta


func level() -> Dictionary:
    return LEVELS[current_level]


func new_run() -> void:
    lives = START_LIVES
    current_level = 0
    map_pieces = 0
    run_time = 0.0
    times_caught = 0
    result = ""
    _load_level()


func next_level() -> void:
    current_level += 1
    map_pieces = 0
    if current_level >= LEVELS.size():
        finish("escaped")
    else:
        _load_level()


func lose_life() -> bool:
    ## Returns true if the run is over.
    lives -= 1
    times_caught += 1
    return lives <= 0

    • change_scene_to_file.call_deferred(...) waits until the end of the frame to swap scenes, so nothing is freed while it's still running.
    • run_time only counts while running is true and the game isn't paused.

## Helpers for the 0x72 DungeonTileset II sprites in res://art/0x72/.


## Builds "idle" and "run" animations from files named
## <character>_idle_anim_f0..3.png and <character>_run_anim_f0..3.png.
static func sprite_frames(character: String) -> SpriteFrames:
    var frames := SpriteFrames.new()
    for anim in ["idle", "run"]:
        frames.add_animation(anim)
        frames.set_animation_speed(anim, 6.0 if anim == "idle" else 10.0)
        frames.set_animation_loop(anim, true)
        for i in 4:
            frames.add_frame(anim, load("res://art/0x72/%s_%s_anim_f%d.png" % [character, anim, i]))
    return frames

    How it works

    • class_name Art registers a global type, so any script can call Art.sprite_frames("ogre").
    • static func means you call it on the class itself, without making an instance.
    • "res://art/0x72/%s_%s_anim_f%d.png" % [character, anim, i] fills in the blanks, building names like ogre_run_anim_f2.png.

    Watch out

    • If a character is missing a frame, load() returns null and the sprite flickers. Check the 32 files from step 4.

    How it works

    • Floating motion mode is for top-down games: no floor and no gravity, so it slides along walls in any direction.

    func _ready() -> void:

    sprite.play("idle")
    lantern.energy = 0.0
    wall_light.energy = 0.0


func _physics_process(delta: float) -> void:
    invulnerable = maxf(invulnerable - delta, 0.0)
    sprite.modulate.a = 0.35 if invulnerable > 0.0 and int(invulnerable * 10.0) % 2 == 0 else 1.0

    if frozen:
        velocity = Vector2.ZERO
        sprite.play("idle")
        return

    var dir := Input.get_vector("move_left", "move_right", "move_up", "move_down")
    var running := Input.is_action_pressed("run")
    velocity = dir * (run_speed if running else walk_speed)
    move_and_slide()

    if dir == Vector2.ZERO:
        sprite.play("idle")
        sprite.speed_scale = 1.0
        return

    sprite.play("run")
    sprite.speed_scale = 1.5 if running else 1.0
    if dir.x != 0.0:
        sprite.flip_h = dir.x < 0.0

    _step_t -= delta
    if _step_t <= 0.0:
        _step_t = 0.2 if running else 0.34
        Sfx.play("step", -5.0 if running else -18.0, randf_range(0.85, 1.15))

    if running:
        _noise_t -= delta
        if _noise_t <= 0.0:
            _noise_t = noise_interval
            Events.noise_made.emit(global_position)

    How it works

    • get_vector returns a direction already normalised, so diagonals aren't faster.
    • velocity = ... then move_and_slide() is the standard CharacterBody2D pattern: you set the speed, Godot handles walls.
    • Two countdown timers made from floats: _step_t for footstep sounds and _noise_t for noise pulses. Subtract delta each frame; when it hits zero, act and reset.
    • Running emits Events.noise_made 4 times a second. Monsters (step 27) decide if they're close enough to hear it.

    Watch out

    • @onready var sprite: AnimatedSprite2D = $Sprite only works if the child is named exactly Sprite.

    scripts/maze_tiles.gd
    class_name MazeTiles
## Builds the TileSet for res://art/maze_tiles.png in code (see tools/make_tiles.py
## for the atlas layout). Wall tiles get a collision square and a light occluder,
## so walls block both movement and the lantern's light.

const SIZE := 16
const SOURCE_ID := 0
const WALL_ROW := 0
const SHIFT_WALL_ROW := 1
const FLOOR_ROW := 2
const SAFE_FLOOR := Vector2i(8, 2)
const EXIT_FLOOR := Vector2i(9, 2)
const SHIFT_HINT_FLOOR := Vector2i(10, 2)

## Mask bits for picking a wall tile.
const N := 1
const E := 2
const W := 4
const FACE := 8


static func build() -> TileSet:
    var ts := TileSet.new()
    ts.tile_size = Vector2i(SIZE, SIZE)
    ts.add_physics_layer()
    ts.set_physics_layer_collision_layer(0, 1)
    ts.set_physics_layer_collision_mask(0, 0)
    ts.add_occlusion_layer()
    ts.set_occlusion_layer_light_mask(0, 1)

    var src := TileSetAtlasSource.new()
    src.texture = load("res://art/maze_tiles.png")
    src.texture_region_size = Vector2i(SIZE, SIZE)
    ts.add_source(src, SOURCE_ID)

    var h := SIZE / 2.0
    var square := PackedVector2Array([Vector2(-h, -h), Vector2(h, -h), Vector2(h, h), Vector2(-h, h)])
    var occluder := OccluderPolygon2D.new()
    occluder.polygon = square

    for row in [WALL_ROW, SHIFT_WALL_ROW]:
        for col in 16:
            var coords := Vector2i(col, row)
            src.create_tile(coords)
            var data := src.get_tile_data(coords, 0)
            data.add_collision_polygon(0)
            data.set_collision_polygon_points(0, 0, square)
            data.add_occluder_polygon(0)
            data.set_occluder_polygon(0, 0, occluder)
    for col in 11:
        src.create_tile(Vector2i(col, FLOOR_ROW))
    return ts

    How it works

    • A physics layer gives tiles collision. Each wall tile gets a 16×16 square, so the player can't walk through it.
    • An occlusion layer gives tiles light occluders. Walls cast shadows from the lantern (step 20).
    • Tile shapes are centred on the tile, so the square runs from (-8, -8) to (8, 8).
    • Floor tiles are created with create_tile but get no collision or occluder.

    Watch out

    • The order matters: ts.add_source(src, ...) must happen before setting collision on tiles, because the tiles need to know which physics layers exist.

    Answer key: scripts/maze_tiles.gd

    if not base.has(c):
        return true
    if shift_cells.has(c):
        var s: Dictionary = shift_cells[c]
        return s.closed_at_start != group_flipped[s.group]
    return base[c] == "#"

    • Digits are stored as floor in base, plus an entry in shift_cells.
    • is_wall decides shifting cells with one comparison: closed at start, unless the group has flipped. != works like XOR here.
    • Anything outside the map counts as a wall, so neighbour checks at the edges are safe.

    scripts/level.gd
    func _paint(c: Vector2i) -> void:
    if is_wall(c):
        var mask := 0
        if is_wall(c + Vector2i.UP): mask |= MazeTiles.N
        if is_wall(c + Vector2i.RIGHT): mask |= MazeTiles.E
        if is_wall(c + Vector2i.LEFT): mask |= MazeTiles.W
        if not is_wall(c + Vector2i.DOWN): mask |= MazeTiles.FACE
        var row := MazeTiles.SHIFT_WALL_ROW if shift_cells.has(c) else MazeTiles.WALL_ROW
        walls.set_cell(c, MazeTiles.SOURCE_ID, Vector2i(mask, row))
        floor_layer.erase_cell(c)
        return
    walls.erase_cell(c)
    var tile: Vector2i
    if base[c] == "s":
        tile = MazeTiles.SAFE_FLOOR
    elif base[c] == "X":
        tile = MazeTiles.EXIT_FLOOR
    elif shift_cells.has(c):
        tile = MazeTiles.SHIFT_HINT_FLOOR
    else:
        # mostly plain floor, sometimes a cracked variant (stable per tile)
        var h := absi(hash(c))
        tile = Vector2i(0 if h % 10 < 8 else 1 + (h >> 4) % 7, MazeTiles.FLOOR_ROW)
    floor_layer.set_cell(c, MazeTiles.SOURCE_ID, tile)

    How it works

    • mask |= MazeTiles.N sets one bit. The finished mask is the column number in the atlas.
    • set_cell(cell, source_id, atlas_coords) places a tile; erase_cell removes one.
    • Walls go on the Walls layer, floors on the Floor layer, never both on one cell.
    • absi(hash(c)) gives a stable "random" number per cell. The floor pattern is the same every time you play, but looks natural.

    func _shift_walls() -> void:
    var n := Phase.blackouts   # 0 on the first blackout
    var changed: Array[Vector2i] = []
    for g in cfg.groups:
        var every: int = cfg.groups[g]
        if (n + 1) % every != 0:
            continue
        if not _flip_is_safe(g):
            continue   # someone is standing where a wall would appear; try next time
        group_flipped[g] = not group_flipped[g]
        for c in shift_cells:
            if shift_cells[c].group == g:
                changed.append(c)
    if changed.is_empty():
        return

    var to_paint := {}
    for c in changed:
        _update_astar(c)
        for dy in range(-1, 2):
            for dx in range(-1, 2):
                var nb: Vector2i = c + Vector2i(dx, dy)
                if base.has(nb):
                    to_paint[nb] = true
    for c in to_paint:
        _paint(c)

    Events.walls_shifted.emit(changed)
    Sfx.play("rumble", -3.0)
    player.shake(3.0, 0.6)
    for c in changed:
        if cell_center(c).distance_to(player.global_position) < 200.0:
            _dust(cell_center(c))

    How it works

    • Phase.blackouts is 0 during the first blackout. (n + 1) % every is 0 when it's this group's turn: every 1st, 2nd or 3rd blackout.
    • Flipping is just group_flipped[g] = not group_flipped[g]. is_wall already reads that.
    • to_paint collects each changed cell and its 8 neighbours in a dictionary (so none is painted twice). Neighbours need repainting because a wall's look depends on what's around it.
    • Changing tiles with set_cell also updates their collision and occluders automatically.

    scripts/level.gd
    func _flip_is_safe(g: int) -> bool:
    var blocked := {}
    # every tile the player's body touches
    var p := player.global_position
    for off in [Vector2(-6, -6), Vector2(6, -6), Vector2(-6, 6), Vector2(6, 6)]:
        blocked[world_to_cell(p + off)] = true

    for i in 24:

func refresh() -> void:
    for i in hearts.get_child_count():
        hearts.get_child(i).texture = HEART_FULL if i < Game.lives else HEART_EMPTY
    if level == null:
        return
    if level.cfg.map_mode == "pieces":
        items_label.text = "Map pieces: %d" % Game.map_pieces
    elif level.cfg.lantern_fuel:
        items_label.text = "Lantern"
    else:
        items_label.text = ""


func _process(_delta: float) -> void:
    if level == null:
        return
    match Phase.phase:
        Phase.P.LIGHT:
            phase_label.text = "LIGHT"
            _bar_fill.bg_color = Color(1, 0.8, 0.4)
        Phase.P.WARNING:
            phase_label.text = "LIGHTS FAILING"
            _bar_fill.bg_color = Color(1, 0.45, 0.3)
        Phase.P.DARK:
            phase_label.text = "BLACKOUT"
            _bar_fill.bg_color = Color(0.55, 0.45, 0.9)
    phase_bar.value = Phase.fraction_left() * 100.0

    var n: int = level.blackouts_until_gate_change()
    var plural := "blackout" if n == 1 else "blackouts"
    if level.gate_open:
        gate_label.text = "Gate open - shuts in %d %s" % [n, plural]
        gate_label.modulate = Color(0.6, 1, 0.7)
    else:
        gate_label.text = "Gate SHUT - opens in %d %s" % [n, plural]
        gate_label.modulate = Color(1, 0.5, 0.45)

    if level.cfg.lantern_fuel:
        items_label.text = "Lantern oil: %d%%" % roundi(level.player.fuel * 100.0)
    safe_label.visible = level.player.is_safe
    items_label.visible = items_label.text != ""


func show_message(text: String) -> void:
    banner.text = text
    if _banner_tween:
        _banner_tween.kill()
    _banner_tween = create_tween()
    _banner_tween.tween_property(banner, "modulate:a", 1.0, 0.15)
    _banner_tween.tween_interval(1.6)
    _banner_tween.tween_property(banner, "modulate:a", 0.0, 0.5)

## Headless smoke test: plays through all three rings with a sped-up blackout
## cycle, walks the player around, lets monsters catch them, and checks the
## run reaches the end screen.
##   Godot --headless --path . --script res://tests/smoke_test.gd

var frames := 0
var log_lines := []
var phase_counts := {}
var shifts := 0
var caught := 0
var levels_seen := {}
var problems := []


var started := false
var want_catch := false
var die_mode := false


func _start() -> void:
    started = true
    die_mode = "die" in OS.get_cmdline_user_args()
    root.get_node("Game").new_run()
    root.get_node("Events").walls_shifted.connect(func(cells): shifts += 1)
    root.get_node("Events").player_caught.connect(func(): caught += 1)
    root.get_node("Phase").changed.connect(func(p): phase_counts[p] = phase_counts.get(p, 0) + 1)


func _process(_delta: float) -> bool:
    if not started:
        _start()
        return false
    frames += 1
    var phase = root.get_node("Phase")
    var game = root.get_node("Game")
    var scene = current_scene
    if scene and scene.name == "Level":
        levels_seen[game.current_level] = true
        # speed up the cycle
        if phase.timer.time_left > 0.4:
            phase.timer.start(0.4)
        var player = scene.player
        # wander: alternate directions
        var dirs = ["move_right", "move_down", "move_left", "move_up"]
        for a in dirs:
            Input.action_release(a)
        Input.action_press(dirs[(frames / 40) % 4])
        if (frames / 90) % 2 == 0:
            Input.action_press("run")
        else:
            Input.action_release("run")
        # every so often: check invariants
        if frames % 30 == 0:
            var pc = scene.world_to_cell(player.global_position)
            if scene.is_wall(pc):
                problems.append("player inside wall at %s (level %d)" % [pc, game.current_level])
            for h in scene.monsters.get_children():
                var hc = h.cell()
                if scene.is_wall(hc):
                    problems.append("monster inside wall at %s" % hc)
        # after a while, let a monster reach the player once per level
        if frames % 300 == 150 or (die_mode and frames % 60 == 0):
            want_catch = true
        if die_mode and want_catch and phase.is_dark() and player.is_safe and scene.monsters.get_child_count() > 0:
            player.global_position = scene.monsters.get_child(0).global_position
        if want_catch and phase.is_dark() and scene.monsters.get_child_count() > 0 \
                and not player.is_safe and player.invulnerable <= 0.0 and not player.frozen:
            var h = scene.monsters.get_child(0)
            h.global_position = player.global_position + Vector2(4, 0)
            want_catch = false
        # then teleport to the exit when the gate is open
        if frames % 1500 == 1400 and not die_mode:
            if scene.gate_open:
                player.global_position = scene.cell_center(scene.exit_cell)
            else:
                player.global_position = scene.cell_center(scene.start_cell)
    if scene and scene.name == "EndScreen":
        print("END: result=", game.result, " lives=", game.lives, " caught=", game.times_caught)
        _report()
        return true
    if frames > 60 * 200:
        print("TIMEOUT in scene ", scene.name if scene else "none", " level ", game.current_level)
        _report()
        return true
    return false


func _report() -> void:
    print("frames=", frames, " levels_seen=", levels_seen.keys(), " phases=", phase_counts,
        " wall_shifts=", shifts, " caught_signals=", caught)
    print("problems: ", problems if problems else "none")

    How it works

    • A script that extends SceneTree replaces Godot's main loop. _process returning true quits.
    • It speeds up the blackout timer to 0.4 s, walks in a square, runs half the time, puts a monster next to the player now and then, and teleports to the exit when the gate is open.
    • Every 30 frames it checks that neither the player nor any monster is inside a wall.
    • With -- die it keeps getting caught to test the game-over path.

    Watch out

    • Autoloads aren't in the tree yet during _initialize(), so the run starts on the first _process frame. The first version of this test crashed for exactly that reason.

## Saves screenshots of the title and each ring in light and dark, for a quick
## visual check. Needs a window (not --headless):
##   Godot --path . --script res://tests/capture.gd -- <output_dir>

var out_dir := "user://captures"
var steps := []
var wait := 0


func _initialize() -> void:
    var args := OS.get_cmdline_user_args()
    if args.size() > 0:
        out_dir = args[0]
    steps = [
        [5, func(): change_scene_to_file("res://scenes/title.tscn")],
        [40, func(): pass],
        [1, func(): _shot("title")],
        [1, func(): root.get_node("Game").new_run()],
    ]
    for ring in 3:
        steps += [
            [30, func(): Input.action_press("move_right")],
            [25, func(): Input.action_release("move_right")],
            [10, func(): _shot("ring%d_light" % ring)],
            [3, func(): root.get_node("Phase").timer.start(0.01)],   # -> warning
            [3, func(): root.get_node("Phase").timer.start(0.01)],   # -> dark
            [45, func(): pass],
            [1, func(): _shot("ring%d_dark" % ring)],
            [1, func(): root.get_node("Game").next_level()],
        ]


func _process(_delta: float) -> bool:
    if wait > 0:
        wait -= 1
        return false
    if steps.is_empty():
        return true
    var s = steps.pop_front()
    s[1].call()
    wait = s[0]
    return false


func _shot(shot_name: String) -> void:
    var img := root.get_viewport().get_texture().get_image()
    DirAccess.make_dir_recursive_absolute(out_dir)
    img.save_png(out_dir.path_join(shot_name + ".png"))
    print("saved ", shot_name)

    How it works

    • It's a list of [frames to wait, action] pairs, run one after another.
    • root.get_viewport().get_texture().get_image().save_png(...) saves exactly what's on screen.
    • This is how the blackout got made darker: the first screenshots showed the maze faintly through it.
